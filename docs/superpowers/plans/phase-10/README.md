# 阶段 10 · 内置效果系统

## 目标与输入

建立脚本和编辑器预览共享的 Rust 内置效果。复用阶段 7 的基础转场与可控时钟、阶段 9 的预览会话和总计划的效果 ID 规则。

## 任务与交付

### P10-01 效果上下文与参数规范

在 `format/` 定义效果 ID、接口版本、时间、目标尺寸、参数类型、默认值、范围与错误诊断。效果输出包括位置、缩放、旋转、透明度和颜色。约定边界时刻、组合顺序、缺失效果及错误回退。用公开值类型隔离 Rust 内部对象。

### P10-02 Rust 效果实现

实现淡入淡出、移动、缩放、旋转、透明度、颜色或亮度和抖动。固定输入与时间下输出可复现，抖动采用可控制的种子。基础滤镜按基准判断。提交每项的起点、中间与终点数值测试，并测量逐帧临时分配。

### P10-03 脚本和编辑器预览接入

编译期解析效果名称、参数和角色默认值，允许脚本覆盖单次 `show` 的效果。编辑器根据同一参数定义生成面板，调用相同 Rust 实现。与 P10-02 在接口确定后并行。交付覆盖默认参数与脚本覆盖的示例。

### P10-04 图像证据及帧时间回归

为每个效果在固定场景保存截图或录屏，用冻结时间验证可重复帧，记录无效果及效果叠加时的帧耗时和临时分配。新增 `scripts/phase10-check.ps1` 验证参数拒绝、确定性和预览一致性。

## 验收与交接

脚本与编辑器预览执行同一组输入，输出相同效果状态。逐项记录帧时间及已知限制，交付版本化的 EffectContext 概念、参数和回退规则给阶段 11。
