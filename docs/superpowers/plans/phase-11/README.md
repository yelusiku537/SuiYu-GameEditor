# 阶段 11 · Go/WASM 自定义效果插件

## 目标与输入

将阶段 10 的效果契约映射到有权限和配额限制的 WASM 宿主。普通内置效果保留独立执行路径。第二目标平台在开工时确定，作为同一插件二进制包的验证环境。

## 任务与交付

### P11-01 插件 ABI、包结构及权限契约

在 `format/` 定义 manifest、唯一 ID、版本、最低引擎版本、能力、参数和 WASM 导出函数。记录 `effect.wasm`、`parameters.json`、预览图、README 与可选源码的归档结构。明确整数和浮点表示、输入输出大小、错误码、主机调用及兼容策略。默认能力排除文件、网络、命令、线程与宿主私有内存。

### P11-02 Go SDK 和官方效果示例

在 `sdk-go/` 固定 Go/TinyGo 到 WASM 的工具链与编译入口，封装参数与 EffectContext，输出一份可分发的示例包。附参数默认值、预览、使用说明及 SDK 测试。ABI 冻结后与 P11-03 并行。

### P11-03 Rust 宿主与失败隔离

在 `host-rust/` 实现 manifest 校验、能力白名单、实例内存限制、执行预算和调用边界。插件失败时禁用或回退，并给出带插件 ID 的日志。测试不允许的导入、版本不匹配、超时、超内存和调用错误，同时验证内置路径继续运行。

### P11-04 双平台加载与自动回归

新增 `scripts/phase11-check.ps1` 和第二平台等效入口，记录 WASM 文件指纹，在两个目标平台加载同一份包并对比效果输出。CI 编译、校验并执行官方示例，保留失败用例和降级行为日志。

## 验收与交接

正常示例在两平台可执行，失败插件按契约隔离，内置效果独立运行。将 ABI、能力规则、包结构与验收矩阵交给阶段 12 的导入界面和阶段 14 的插件文档。
