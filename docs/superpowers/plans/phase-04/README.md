# 阶段 04 · 新脚本语言 v0 与 Go 编译器

## 目标与输入

把 `.story` 编译成可由阶段 3 运行时执行的 v0 包。阶段 1 提供语义建议，阶段 2 提供包和定位契约。语言范围为 `label`、`jump`、`call`、`return`、`scene`、`show`、`hide`、对白、字符串、数字、布尔值和注释，菜单在下一阶段接入。

## 任务与交付

### P04-01 语法、诊断与 IR 契约

定义缩进、换行、引号、注释、行列单位、AST 节点和源码区间。为重复 label、未定义跳转或资源、非法缩进等诊断分配稳定代码。约定 opcode、参数、跳转目标、调用栈及空栈 `return` 的行为，附示例和跨语言测试向量。

### P04-02 Go 前端、语义与发包

在 `compiler-go/` 实现 lexer/parser，做项目范围的符号和角色/立绘/资源引用解析。将 AST 降级至已冻结 IR，生成 source map 和游戏包。以稳定文件顺序、诊断和 ID 规则覆盖 Unicode、重复定义及行列边界。

### P04-03 Rust 最小执行器

与 P04-02 并行，根据 IR 契约实现指令读取、跳转、调用与返回、对白事件和基本演出指令。给非法目标或指令产出可经 source map 解释的错误，交付 `label → say → jump → return` 的可重复执行轨迹。

### P04-04 增量编译和端到端检查

支持单脚本及项目入口，建立文件内容与依赖缓存。只改对白时验证未变化文件命中缓存，修改共享符号时验证必要的依赖重新分析。比较增量与全量字节，记录发包和诊断金样，累计至少 30 个 parser/compiler 用例。

## 验收与交接

新增 `scripts/phase04-check.ps1`，编译合法示例、执行指令轨迹并比对错误行列、确定性与增量结果。交给阶段 5 的是项目编译入口、调用栈语义以及稳定的角色、立绘和资源 ID。
