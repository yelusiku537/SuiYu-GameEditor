# 阶段 05 · 第一个完整剧情闭环

## 目标与输入

以阶段 4 的编译器与执行器、阶段 3 的窗口和图层为基础，让一个最小项目能编译、打包、显示背景和立绘、阅读对白、选择分支并结束。支持 `scene`、`show`、`hide`、`say`、`label`、`jump`、`call`、`return` 和 `menu`。

## 任务与交付

### P05-01 菜单编译与输入状态机

在 `format/`、`compiler-go/` 和 `runtime-rust/` 冻结菜单 ID、选项次序与跳转目标，记录包兼容影响。实现对白等待、菜单等待、继续和结束。定义一次输入最多推进一次、菜单关闭后焦点恢复和无效选项处理。提交覆盖两条分支及错误目标的轨迹测试。

### P05-02 对话框、选项与角色层

实现最小对白和选项界面，支持鼠标、键盘、中文文字和指定层序。验证同角色立绘替换、隐藏和换场后的图层清理。与 P05-01 对齐事件后并行，登记字体及样例素材来源，补交截图和键盘操作用例。

### P05-03 双分支示例与一键运行

在 `examples/` 提供背景、角色、至少三句对白和双选项示例，两条分支都正常结束。新增 `scripts/phase05-demo.ps1` 串联 Go 编译、发包、Rust 启动，并传递首个失败的退出码。提供操作顺序、预期画面和已知限制。

### P05-04 自动回归与桌面验收

新增 `scripts/phase05-check.ps1`，在无窗口测试中跑完两个分支，比较重复运行的事件序列，并校验错误跳转定位。在 Windows 记录示例的文字、层序、选项、路线和退出行为。将失败路径及构建命令接入 CI。

## 验收与交接

从根目录执行上述两个脚本。示例按预期进入两个 label 并以退出码 0 结束。到达首个可玩里程碑后，交给阶段 6 的是暂停点、调用栈、菜单事件和分支示例。
