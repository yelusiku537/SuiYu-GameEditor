# 阶段 07 · 资源、音频、转场与性能基线

## 目标与输入

在阶段 3 的加载接口及阶段 5–6 的剧情和状态之上，交付有预算的资源生命周期、基础声音、立即切换和淡入淡出，并建立同条件 Ren'Py 基线。

## 任务与交付

### P07-01 按需加载与缓存预算

为 CPU 图片、GPU 纹理、音频和脚本内存分别记录用量。实现资源引用约定、淘汰条件、预算上限和诊断。覆盖超预算时淘汰闲置缓存、不释放使用中的资源、缺图、错误格式与大图。用重复切场景的曲线区分缓存预热与持续增长。

### P07-02 音频播放与状态恢复

新增 BGM 与音效通道的播放、停止、切换及错误处理。约定解码、缓冲、设备不可用、循环与读档后的行为。用固定许可音频和可替换音频后端测试命令次序，再在 Windows 记录实际播放。

### P07-03 基础转场

实现立即切换和淡入淡出，明确时长、时钟、透明度、跳过、重复触发和资源持有时间。复用 P07-01 的预算，在正常完成、快速连续切换和退出时验证临时纹理已释放。

### P07-04 对照基准及复验入口

在 `benchmarks/` 固定 Ren'Py 和新引擎版本、设备、分辨率、场景及资源，记录冷/热启动、首次切场、编译（全量与增量）、打包、帧时间 P95/P99、CPU 峰值、GPU 预算和长时内存斜率。记录测量方法、重复次数、误差范围和原始结果。

## 验收与交接

新增 `scripts/phase07-check.ps1`，执行坏资源、超预算、音频与转场回归。归档长时间切场景结果与至少一组对照数据。阶段 8 获得 `with` 的基础映射，阶段 10 获得时间和转场接口，阶段 13 沿用基准场景。
