# 阶段 08 · .rpy 分级转换器

## 目标与输入

在 `translator-go/` 将 `.rpy` 静态转换为 `.story` 和项目声明，接入阶段 4 的编译链。使用阶段 1 的兼容性矩阵，依赖阶段 6、7 提供状态与基础转场能力。按语义覆盖核定每个语法变体的转换等级。

## 任务与交付

### P08-01 分级规则与输出契约

列出直接转换项 `label`、`scene`、`show`、`hide`、`with`、对白、`menu`、`jump`、`call`、`return`、受支持的 `define/default`。对基础表达式、赋值、简单 ATL/screen、资源声明列警告与判定条件。记录任意 Python、复杂 ATL/screen、自定义 displayable、动态路径和第三方插件的未支持策略，及参考 SDK 保留运行的限制。

### P08-02 tokenizer、语法识别与发射

实现缩进、字符串、注释和多文件位置的解析，保留未识别片段及范围。生成新脚本和角色、立绘、资源声明，输出顺序可复现，并通过新编译器校验。若此前只预留了状态模型，先为直接转换承诺的 `define/default` 补齐消费端并测试存读档语义。以 `define Character`、图片声明和双分支示例覆盖端到端路由。

### P08-03 转换模式、诊断与报告

实现 `--strict` 和 `--best-effort`。严格模式遇到未支持内容时失败且不留下可误用的半成品，尽力模式输出清楚标记的结果和人工处理清单。诊断含文件、行列、规则、原因和建议，报告含成功、警告、失败计数，并为不可执行输出写出状态。

### P08-04 金样与原版对照

在 `compatibility-tests/fixtures/` 提交至少 50 个输入、输出与预期诊断用例。对最小项目在固定 SDK 和新运行时执行同一输入轨迹，记录设计差异并补齐迁移指南。测试准备可在 P08-01 后与 P08-02 并行。

## 验收与交接

新增 `scripts/phase08-check.ps1` 验证金样、两种模式、严格失败退出码、迁移报告和最小项目的执行轨迹。进阶项的限制随支持矩阵交给编辑器和发布文档。
