# 阶段 03 · Rust 运行时最小骨架

## 目标与输入

在 Windows 桌面从阶段 2 的包加载背景，稳定接收输入、绘制并退出。消费 Go 生成的包，Rust 独立运行。脚本解释和剧情 UI 接在后续阶段。

## 任务与交付

### P03-01 Rust 平台层与循环

在 `runtime-rust/` 建立 workspace/crate 边界，记录窗口库、GPU 后端及固定或可变时间步的 ADR。实现窗口创建、尺寸调整、输入事件、最小化时的调度和关闭流程。交付可以在无 GPU 的测试里驱动的时间和输入接口，以及窗口 smoke。

### P03-02 渲染和资源接口

与 P03-01 对齐窗口表面后并行开发，使用 wgpu 绘制纯色、纹理和文本占位。确定上传、替换、释放和 fallback 行为，显式区分资源 ID、已加载资源与 GPU 句柄。验证缺图、解码失败、目标表面失效的可读错误。

### P03-03 加载、运行和观测

接入阶段 2 manifest 与版本检查，让运行时命令从最小游戏包读取入口与背景。增加默认可关闭的调试叠层，采集 FPS、CPU 帧时间、资源数、缓存大小并标记采样窗口。创建有图及缺图包，分别验证成功和错误退出。

### P03-04 Windows 验证与资源稳定性

将无 GPU 单测、读取集成测试和 Windows GUI smoke 分开记录。运行至少 10 分钟，采样工作集与缓存指标，记录预热段、退出码和采样环境，检查预热后是否持续增长。交付日志、截图和已知驱动约束。

## 验收与交接

新增 `scripts/phase03-check.ps1`，在 Windows 原生环境或具有图形能力的 Windows runner 验证背景、叠层和窗口退出，其他 runner 执行无窗口测试。阶段 4 得到输入事件与运行入口，阶段 5 得到绘制层和最小资源接口。
