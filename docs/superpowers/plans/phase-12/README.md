# 阶段 12 · 声明式 UI 和可编辑风格包

## 目标与输入

阶段 9 编辑器与 Rust 运行时共享可版本化的 UI 模型，导入风格后能继续改动语义结构。复用阶段 2 的包边界、阶段 5 的剧情事件和阶段 10 的动画参数。

## 任务与交付

### P12-01 UI schema 与运行时版本协商

在 `format/` 定义组件树、稳定节点 ID、布局约束、theme tokens、字体、间距、颜色、圆角、阴影、动画、动作和资源引用。定义动作白名单、版本检查、缺失组件与未知字段的处理。附含 NameLabel、DialogueText 和 ContinueButton 的完整语义例子。

### P12-02 运行时布局、绘制和动作

实现默认 Panel、Label、Button 与选项列表，对接剧情继续和选择事件。提交尺寸变化、焦点顺序、鼠标与键盘、长文本和缺资源测试，并保留对话框和选项菜单样例。

### P12-03 编辑器视图与双向编辑

与 P12-02 共用 schema，通过组件树、属性、主题和预览面板修改 UI。保存为可读源码，并验证打开、修改、保存、重新打开及运行的语义往返。错误定位到节点 ID 或属性，编辑器仅依赖公开的 UI 数据契约。

### P12-04 风格包导入、复制与迁移

风格包随附可编辑源文件、资源、预览和版本说明。导入时检查组件版本与资源冲突，支持复制到独立本地版本。先在副本尝试迁移，失败时恢复原有项目内容并发出诊断。夹具覆盖旧版升级、失败回退及复制后编辑。

## 验收与交接

新增 `scripts/phase12-check.ps1`，使用同一份 UI 源在编辑器和运行时预览，比较动作轨迹与语义往返，确认失败迁移保留原文件。交付 schema、官方风格示例、迁移方法及限制给阶段 14。
